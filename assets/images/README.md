# Image replacement guide

Use descriptive lowercase filenames with hyphens.

## Headshot
- Add: `headshot.jpg`
- Recommended: 1200 × 1500 px or larger, 4:5 portrait crop
- Replace the `.portrait-placeholder` element in `index.html` with:
  `<img class="portrait" src="assets/images/headshot.jpg" alt="Portrait of Krystal Zhang">`

## Project images
Create one folder per project:
- `project-1/`
- `project-2/`
- `project-3/`

Recommended hero image: at least 1800 px wide. Avoid identifiable participant images unless public use is authorized. Add meaningful alt text describing the research content rather than the file appearance alone.

## Logos
Store approved logos in `logos/`. Prefer SVG when the institution provides an official SVG; otherwise use a transparent PNG.
